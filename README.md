# 🦥 Slothify — AI That Does the Boring Work

*You relax. AI handles the boring bits.*

Slothify is a cozy, AI-powered productivity workspace built for the Hacktoberfest 2026 DEV Challenge. It helps people save time by turning long, complicated text into short, actionable information—and optionally reading it aloud.

Reading dense college emails, 10-page study notes, or complicated articles is tedious. Slothify automates this process using a clean "Cozy Pastel Productivity" interface and open-weight AI, allowing users to reduce their mental effort and get their time back.

## ✨ Features

* **✨ Summarize:** Condenses long text into a quick overview.
* **📌 Key Points:** Extracts essential information and details.
* **✅ Make a Checklist:** Converts paragraphs into actionable tasks.
* **💡 Simplify:** Explains complicated text in simple, accessible language.
* **🔊 Listen:** Reads the AI-generated result aloud using text-to-speech.

## ⚙️ How It Works

| Component | Technology | Functionality |
| --- | --- | --- |
| **Frontend** | React & Tailwind CSS | Provides the responsive, minimal UI and manages user interactions and state. |
| **Backend** | Python & FastAPI | Acts as the bridge, receiving frontend requests and routing them to the AI services. |
| **AI Brain** | Google Gemma & Ollama | Runs locally on the user's machine to process the text and generate tailored responses. |
| **Voice Engine** | ElevenLabs API | Converts the text output generated by Gemma into natural-sounding spoken audio. |

## 🏆 Hacktoberfest Categories

### Best Use of Gemma

Gemma is the core intelligence driving Slothify. Served locally through Ollama, this open-weight model processes the user's text on their own computer. The application demonstrates Gemma's flexibility by dynamically prompting the model to transform a single input into four distinct, useful outputs (summaries, bulleted key points, actionable checklists, or simplified explanations). By utilizing local inference, Slothify ensures that sensitive inputs—such as personal emails or private study notes—never need to be sent to a hosted language-model API for text processing.

### Best Use of ElevenLabs

Slothify integrates the ElevenLabs Text-to-Speech API to make productivity more accessible. Instead of forcing users to read the AI-generated summaries, the application features a seamless "Listen" capability. The FastAPI backend securely routes the generated text to ElevenLabs, returning high-quality, natural-sounding audio narration directly to the browser. This turns tedious reading tasks into a passive listening experience.

## 🌱 Why Open-Source AI Matters

Slothify champions open-source and local AI processing. By running Gemma via Ollama, the core text-processing operates entirely offline (once the model is downloaded). This provides complete data privacy and eliminates per-request API costs for text generation. Users maintain full control over their data and have the flexibility to swap out models based on their hardware capabilities.

## 🚀 Setup Instructions

### Prerequisites

* Node.js and npm
* Python 3.8+
* [Ollama](https://ollama.com/) installed locally
* An [ElevenLabs](https://elevenlabs.io/) API key

### 1. Set up Local AI (Gemma)

Keep Ollama running in the background and pull the Gemma model:

```bash
ollama pull gemma:2b

```

### 2. Set up the Backend

```bash
cd backend
python -m venv venv
# Activate the virtual environment (Windows: venv\Scripts\activate | Mac: source venv/bin/activate)
pip install fastapi uvicorn httpx pydantic python-dotenv



Create a `.env` file in the `backend` directory and add your key:

```env
ELEVENLABS_API_KEY=your_api_key_here

```

Start the backend server:

```bash
uvicorn main:app --reload

```

### 3. Set up the Frontend

Open a new terminal and navigate to the frontend directory:

```bash
cd frontend
npm install
npm run dev

```
