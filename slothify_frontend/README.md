# Slothify Frontend

This is the fully styled React frontend for Slothify, matching the Cozy Pastel Productivity theme.

## Quick Start

1. Open your terminal in this folder.
2. Run `npm install` to install React, Vite, and Tailwind CSS.
3. Run `npm run dev` to start the development server.
4. Open the link provided in your terminal (usually `http://localhost:5173`).
